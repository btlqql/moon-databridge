# DataBridge0.4.0项目参考说明

账号btlqql；日期2026-10-22；许可Apache-2.0；主要语言MoonBit。

本项目实现CSV／JSONL／对象行批次的类型转换、约束检查、组合筛选、去重、唯一右键连接、排序、聚合、画像与CSV导出。领域结果附带输入、拒绝、筛除、去重、连接丢弃、聚合前后数量的核对账目和拒绝质量门槛。

本轮先核对公开main在9月1日后已有13次提交，再实际修复字典序比较、空输入配置漏检和整数缩放类型不变量。新增14个回归用例，核心34项，CLI/API32项；独立Python另核对40个流水线、1000条输入记录。详细机制、接口、复现命令和边界见README及review-20261022.md。

未收到后续新版审核的完整具体意见，因此不能断言提交次数仍是最新驳回原因。公共GitHub提交核验脚本可记录主分支、固定head、截止日期、提交URL和真实作者／提交者日期。保留原历史，不倒填日期或用空提交凑数。完整本轮参考材料另附当前CI、固定发行和注册表安装证据。

当前为内存批次处理，不是流式ETL／数据库写入平台。共享值类型和CLI如实披露，不作为独立领域创新。旧接口弃用提醒仍存在。公开发布与比赛报名表更新分别记录，本参考说明不构成主办方通过回执。
